Connexion GitHub

Cette page modifie directement la liste des membres sur GitHub. Il te faut une clé d'accès personnelle (token), à créer une seule fois :

  1. Ouvre github.com → nouveau token.
  2. Nom : Admin Ivalys. Expiration : au choix (90 jours, par exemple).
  3. Repository access : « Only select repositories », puis choisis aion2-guilde.
  4. Permissions → Repository permissions : Contents sur « Read and write », et Actions sur « Read and write » (pour le bouton « Relancer la mise à jour »).
  5. Clique sur « Generate token », copie la clé et colle-la ici.

La clé reste dans ton navigateur et n'est envoyée qu'à GitHub. Chaque officier qui doit gérer les membres crée la sienne, après avoir été ajouté comme collaborateur du dépôt.
