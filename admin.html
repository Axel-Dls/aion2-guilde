Connexion GitHub

Cette page modifie la liste des membres directement sur GitHub. Il te faut une clé d'accès personnelle (token), à créer une seule fois :

  1. Ouvre GitHub → nouveau token (« Fine-grained »).
  2. Repository access : « Only select repositories » → aion2-guilde.
  3. Repository permissions : Contents → Read and write, et Actions → Read and write.
  4. « Generate token », puis colle la clé ci-dessous.
